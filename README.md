 Computer Vision & Deep Learning Project

Bu repository **Computer Vision** (Kompyuter ko'rish) va **Deep Learning** (Chuqur o'rganish) texnologiyalari bo'yicha amaliy ishlar, skriptlar va o'quv materiallarini o'z ichiga oladi.

## 📂 Loyiha tuzilmasi (Directories)

- **`InsightFace/`** - InsightFace yuzni aniqlash va tanish kutubxonasiga oid skriptlar.
- **`Opencv/`** - OpenCV kutubxonasi yordamida tasvirlarni qayta ishlash, filtrlash, konturlarni aniqlash va boshqa amaliyotlar.
- **`cvzone/`** - Cvzone yordamida qo'l barmoqlarini sanash, yuzni aniqlash va boshqa qiziqarli vazifalar.
- **`face_recognition/`** - Yuzni tanish (Face Recognition) bo'yicha algoritmlar va modellar (`.pkl` va `.tflite` fayllari bilan birga).
- **`yolo/`** - YOLO obyektlarni aniqlash modellari (`.pt` fayllar) va skriptlari.
- **`Images/`** & **`Videos/`** - Sinov va amaliyotlar uchun ishlatiladigan rasm va video materiallari.

---

## 🚀 O'rnatish va Ishga tushirish

Loyihadagi skriptlarni ishga tushirish uchun zarur kutubxonalarni o'rnating:

```bash
pip install opencv-python ultralytics cvzone insightface face_recognition
```
