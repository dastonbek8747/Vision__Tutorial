# 👁 Vision Tutorial (OpenCV + InsightFace)

Kompyuter ko'rish (Computer Vision) bo'yicha o'quv loyihasi: OpenCV asoslari va yuzni tanish.

---

## ✨ Mavzular

**OpenCV:**
- 📖 Rasm o'qish (`read.py`), o'lcham o'zgartirish (`resize.py`)
- 🎨 Filtrlar (`filters.py`), rang almashtirish (`exchange_color.py`)
- 🔲 Threshold (`thershold.py`), chizish (`draw.py`)
- 🚗 Chekka aniqlash (`chekkani_aniqlash.py`), hisoblash (`counter.py`)
- 📹 Real vaqt (`real_time.py`)

**InsightFace:**
- 🙂 Yuzni tanish (`InsightFace/day_1.py`)

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **OpenCV** | Rasm/video bilan ishlash |
| **InsightFace** | Yuzni tanish |

## ⚙️ O'rnatish

```bash
git clone https://github.com/dastonbek8747/Vision__Tutorial.git
cd Vision__Tutorial
python -m venv venv
source venv/bin/activate
pip install opencv-python insightface
```

---

## ▶️ Ishga tushirish

```bash
python Opencv/read.py
python InsightFace/day_1.py
```

`Images/` va `Videos/` papkalarida namuna materiallar mavjud. `ROADMAP.html` — o'quv rejasi.
