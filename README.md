# Computer Vision Tutorial

> A learning repo for computer vision: OpenCV basics, face recognition, InsightFace and YOLO examples.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## What Is Inside

| Folder | Content |
|---|---|
| `Opencv/` | Image read/write, filters, thresholds, edge detection, drawing, colour spaces, contours. |
| `face_recognition/` | Face detection and recognition samples. |
| `InsightFace/` | Face embedding and comparison examples. |
| `yolo/` | Object detection with YOLO. |

## Quick Start

```bash
git clone https://github.com/dastonbek8747/computer-vision-tutorial.git
cd computer-vision-tutorial
python -m venv .venv && source .venv/bin/activate
pip install opencv-python ultralytics insightface face-recognition
```

Open `ROADMAP.html` in a browser to follow the learning path. Each script is standalone.

## Why This Repo Exists

These are my study notes while learning computer vision. The skills here feed into my face-access project and the vision tools in my multi-agent assistant.
